# Alisa Decor & Balloons

Главная страница сайта студии праздничного оформления воздушными шарами (Комрат).

Статический сайт: один `index.html` и папка `img/`. Сборка не нужна.

## Публикация на GitHub Pages

1. Залейте содержимое этой папки в корень репозитория.
2. Settings → Pages → Build and deployment → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

## Перед запуском

- Заменить сгенерированные фото на реальные работы студии.
- Проверить цифры в блоке «О нас» и отзывы.
- Добавить страницы документов из подвала и румынскую версию юридических страниц.
