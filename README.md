# Alisa Decor & Balloons — интернет-магазин

Статический сайт (один index.html + img/). Публикуется на Vercel: https://alisa-decor.vercel.app

Демо-версия: названия, цены, фото и отзывы — примеры, заказы никуда не отправляются.

## Визуальная проверка перед правками

В папке `tools` лежит скрипт, который снимает 8 страниц на ширинах 390, 768 и 1440 и сравнивает их с эталоном.

```
cd tools
npm i && npx playwright install chromium
npm run baseline   # до правок
npm run check      # после правок: покажет, что изменилось, и горизонтальную прокрутку
```

Картинки отличий — в `tools/shots/diff`. Папки `shots` и `node_modules` в git не попадают.
